## 0. Konvensiyalar
- **PK:** `id BIGINT GENERATED ALWAYS AS IDENTITY`. **Tashqi id:** `public_id UUID NOT NULL UNIQUE` (API’da ko‘rinadigan jadvallarda). `public_id` sir emas.
- **Vaqt:** `created_at`, `updated_at` `timestamptz NOT NULL DEFAULT now()`; boshqa vaqtlar `timestamptz`.
- **Versiya:** agregatlarda `version INTEGER NOT NULL DEFAULT 1 CHECK (version >= 1)`.
- **Pul:** `*_minor BIGINT`, `currency CHAR(3) NOT NULL DEFAULT 'UZS' CHECK (currency = 'UZS')`.
- **O‘lchov birliklari (D14, yagona):** og‘irlik `*_g INTEGER`; **hajm — bagaj ham, yuk ham — `*_ml INTEGER`**; o‘lcham `*_cm INTEGER`; masofa `*_m INTEGER`; davomiylik `*_s` / `*_minutes INTEGER`. Float va litr ustunlari yo‘q.
- **Status:** `TEXT NOT NULL` + `CHECK (col IN (...))`, qiymatlar `app/contracts/enums.py`dan.
- **Immutable:** `BEFORE UPDATE OR DELETE` trigger (naqsh: `20260626_0024_make_audit_logs_immutable.py`); ruxsat etilgan ustunlar ko‘rsatiladi.
- **Geo:** `geometry(Point|LineString, 4326)`; masofa `::geography`; GiST.
- **FK:** modul chegarasidan o‘tadi, ORM relationship o‘tmaydi (ADR-0001).
- **Sirlar:** kodlar va token’lar plaintext saqlanmaydi (ADR-0018).
- **Legacy (Q4):** v1 buyurtmalar v2 yozuv jadvallarida qator bo‘lmaydi; faqat read-only view (§1.12).
- **Audit:** `audit_logs` qayta ishlatiladi; `entity_id` `Integer` (`app/models/audit_log.py:15`) — BIGINT id’lar uchun kuzatiladi.
- **PG test muhiti (A0b, ishchi daraxtda tekshirildi):** `docker-compose.test.yml` — wave 1.5 dan prod bilan bir xil lokal image `docker/postgis/Dockerfile` (`postgres:16.15-trixie` + PostGIS 3.5.3, bir xil initdb argumentlari; avval `postgis/postgis:16-3.5`), DB/user `elchi_test` `127.0.0.1:45432` (Q76; avval 55432 — Windows excluded diapazonida edi), Redis `127.0.0.1:36379`; `tests/pg/conftest.py` — standart URL shu, DB nomida `test` tokeni va localhost guard majburiy (`ELCHI_TEST_PG_ALLOW_REMOTE=1` bilan chetlab o‘tiladi), `ELCHI_TEST_PG_REQUIRED=1` bo‘lsa server yo‘qligi skip emas, fail. Migratsiya smoke — `tests/pg/test_migrations_smoke.py` (A0b).
